Vet Clinic API

Gestão de clínica veterinária: autenticação JWT, controle de acesso por papéis, agendamento de consultas com validação de conflito de horário e prontuários médicos.

Abrir sistema Documentação (Swagger) Ver no GitHub

Funcionalidades

Autenticação & papéis

Login com JWT e três papéis: ADMIN, VET (veterinário) e RECEPTIONIST.

Clientes & pets

Cadastro de tutores e seus pets, com relacionamento 1:N e paginação.

Agendamento

Consultas com validação de conflito de horário por veterinário e transições de status controladas.

Prontuários médicos

Vinculados a consultas concluídas — só é possível registrar após status COMPLETED.

Catálogo de serviços

Consulta, vacinação, banho e tosa, e outros serviços da clínica.

Documentação viva

OpenAPI/Swagger navegável, com autenticação Bearer testável direto na UI.

Stack

Java 21 Spring Boot 3.3 Spring Security + JWT Spring Data JPA H2 (dev) / PostgreSQL (prod) springdoc-openapi JUnit 5 + MockMvc Docker
